# Salvadanaio

App per contare le monete di due salvadanai: uno con le monete da 0,50 €, 1 € e 2 €, l'altro con quelle da 5, 10 e 20 centesimi.

Di Gelu Inc.

## Cosa fa

- Aggiungi le monete con un tocco, oppure tante insieme con "+ N"
- Totale di ogni salvadanaio e totale complessivo
- Obiettivo di risparmio con barra di avanzamento
- Storico delle monete e degli svuotamenti
- Pulsante per nascondere le cifre
- Si installa sul telefono e funziona anche senza internet

I dati restano solo sul telefono, nella memoria del browser.

## Pubblicarla con GitHub Pages

1. Crea un repository nuovo, per esempio `salvadanaio`.
2. Carica **il contenuto** dello zip nella radice del repository: `index.html` deve stare in primo piano, non dentro una cartella.
3. Vai su **Settings → Pages**, scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`, poi **Save**.
4. Dopo un minuto l'app è su `https://TUO-NOME.github.io/salvadanaio/`.

## Installarla

- **Android** (Chrome, Edge, Samsung Internet): apri il link e tocca "Installa l'app sul telefono".
- **iPhone** (Safari): tasto Condividi → "Aggiungi alla schermata Home".

## Aggiornarla

Dopo una modifica cambia il numero in `sw.js` (`salvadanaio-v1` → `salvadanaio-v2`), così i telefoni scaricano la versione nuova.
